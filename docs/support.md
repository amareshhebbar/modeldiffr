## What to include in a bug report

* The output of `modeldiffr --version`
* The exact command you ran
* The full error output, or the `report.json` that looks wrong
* Your Python version, operating system, and GPU if you used one

The more of this the report has, the faster it gets fixed. A failing `modeldiffr verify` result is always treated as a bug until shown otherwise.

## Response times

Modeldiffr is maintained by one person today. Bugs that make a report wrong or unverifiable come first; everything else is answered as time allows, usually within a week.
