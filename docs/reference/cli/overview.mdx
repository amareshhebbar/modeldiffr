```text
usage: modeldiffr [-h] [--version] {audit,suites} ...

Audit what changed between a base LLM and a derivative model.
```

| Command | Purpose |
| --- | --- |
| [`audit`](/reference/cli/audit) | Compare a base model with a derivative model |
| [`suites`](/reference/cli/suites) | List available suites |

## Global options

<ParamField path="--version" type="flag">
  Print `modeldiffr 0.1.0` and exit.
</ParamField>

<ParamField path="-h, --help" type="flag">
  Show help for the command or subcommand.
</ParamField>

## Entry points

All three are equivalent:

```bash
modeldiffr audit base derivative
python -m modeldiffr audit base derivative
```

```python
from modeldiffr.cli import main

exit_code = main(["audit", "base", "derivative"])
```

`main` returns the exit code instead of exiting, which makes it easy to call from tests. See [exit codes](/reference/exit_codes).

## Output streams

| Stream | Content |
| --- | --- |
| stderr | Progress lines prefixed with `[modeldiffr]`, and errors |
| stdout | Metric summary table, notes, and report paths |
