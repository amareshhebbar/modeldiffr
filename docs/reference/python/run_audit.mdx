## Signature

```python
def run_audit(
    base: Backend,
    derivative: Backend,
    suite: Suite,
    seed: int = 0,
    n_resamples: int = 2000,
    progress: Callable[[str], None] = _noop,
) -> dict
```

## Parameters

<ParamField path="base" type="Backend" required>
  The reference model. Any object implementing the [Backend protocol](/reference/python/backend_protocol), usually an [`HFBackend`](/reference/python/hf_backend).
</ParamField>

<ParamField path="derivative" type="Backend" required>
  The model under audit.
</ParamField>

<ParamField path="suite" type="Suite" required>
  Items to evaluate. Get a built in one with `get_suite("quick")`.
</ParamField>

<ParamField path="seed" type="int" default="0">
  Bootstrap seed.
</ParamField>

<ParamField path="n_resamples" type="int" default="2000">
  Bootstrap resamples per metric.
</ParamField>

<ParamField path="progress" type="Callable[[str], None]">
  Called with a short message at each stage. Defaults to a no op.
</ParamField>

## Returns

A dict matching the [report schema](/reference/report_schema). Key fields:

<ResponseField name="metrics" type="list[dict]">
  One entry per metric with means, delta, interval, and `significant`.
</ResponseField>

<ResponseField name="verdict" type="dict">
  <Expandable title="properties">
    <ResponseField name="changed" type="list[str]">
      Names of metrics that changed significantly.
    </ResponseField>
    <ResponseField name="any_change" type="bool">
      True when `changed` is not empty.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="notes" type="list[str]">
  Run notes, such as a skipped divergence metric.
</ResponseField>

<ResponseField name="items" type="dict">
  Per item results for both models.
</ResponseField>

## Execution order

1. Capability scoring on base, then derivative.
2. Over refusal generation on base, then derivative.
3. Output divergence, only when `base.vocab_signature() == derivative.vocab_signature()`.
