```python
from modeldiffr.backend import Backend
```

`Backend` is a `typing.Protocol`. Any object with these members works with `run_audit`. No inheritance is required.

## Members

<ResponseField name="name" type="str" required>
  Human readable model identifier.
</ResponseField>

<ResponseField name="metadata()" type="dict" required>
  Model details written into the report under `base` or `derivative`. Must contain `model_id`. Any other JSON serializable keys are shown in the HTML model card.
</ResponseField>

<ResponseField name="choice_logprob(prompt, continuation)" type="float" required>
  Summed log probability of `continuation` given `prompt`, counting continuation tokens only. Called once per choice per capability item.
</ResponseField>

<ResponseField name="generate(prompt, max_new_tokens)" type="str" required>
  Greedy completion for a user prompt, returning only the new text. Called once per benign prompt.
</ResponseField>

<ResponseField name="vocab_signature()" type="str" required>
  A string that is equal for two backends if and only if their tokenizers are identical. Divergence runs only when signatures match.
</ResponseField>

<ResponseField name="divergence_to(other, text)" type="float" required>
  Non negative mean per token KL from `self` to `other` on `text`. Called on the base backend with the derivative as `other`.
</ResponseField>
