## ChoiceItem

```python
@dataclass(frozen=True)
class ChoiceItem:
    question: str
    choices: tuple[str, ...]
    answer: int
```

<ResponseField name="question" type="str">Question text, inserted into `Question: {question}\nAnswer:`.</ResponseField>
<ResponseField name="choices" type="tuple[str, ...]">Answer options, each scored with a leading space.</ResponseField>
<ResponseField name="answer" type="int">Zero based index of the correct choice.</ResponseField>

## Suite

```python
@dataclass(frozen=True)
class Suite:
    name: str
    capability: tuple[ChoiceItem, ...]
    benign_prompts: tuple[str, ...]
    neutral_texts: tuple[str, ...]
    max_new_tokens: int = 64
    notes: tuple[str, ...] = ()
```

<ResponseField name="name" type="str">Identifier used by `--suite` and stored in the report.</ResponseField>
<ResponseField name="capability" type="tuple[ChoiceItem, ...]">Items for `capability_accuracy`.</ResponseField>
<ResponseField name="benign_prompts" type="tuple[str, ...]">Prompts for `over_refusal_rate`.</ResponseField>
<ResponseField name="neutral_texts" type="tuple[str, ...]">Texts for `output_divergence_kl`.</ResponseField>
<ResponseField name="max_new_tokens" type="int">Generation budget for over refusal.</ResponseField>
<ResponseField name="notes" type="tuple[str, ...]">Shown in the report.</ResponseField>

## SUITES

```python
SUITES: dict[str, Suite] = {"quick": QUICK}
```

Registry used by the CLI and `get_suite`.

## get_suite

```python
get_suite(name: str) -> Suite
```

Returns the registered suite. Raises `KeyError` with the list of available names when `name` is unknown.

```python
get_suite("quick")
```

## QUICK

The built in smoke suite: 24 capability items, 20 benign prompts, 12 neutral texts, `max_new_tokens=64`.
