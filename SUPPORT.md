# Getting Help

* **Usage questions:** open a GitHub Discussion, or an issue with the question label.
* **Bugs:** use the bug report issue template.
* **Feature ideas:** use the feature request template.
* **Security issues:** follow [SECURITY.md](SECURITY.md). Do not post them publicly.
* **Everything else:** hebbar.gvamaresh@gmail.com

When asking for help, include your Modeldiffr version (`modeldiffr --version`), the command you ran, and the full error output.
